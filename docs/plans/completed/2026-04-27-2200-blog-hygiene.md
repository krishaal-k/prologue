# Blog Hygiene Bundle — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Round out the blog post page (`/blog/<slug>`) with the hygiene basics — published date, tag chips, "back to blog" link, automatic `—Krishaal` sign-off, and OG/Twitter metadata — and re-publish the welcome post from its Obsidian draft so embedded links survive.

**Architecture:** All visible additions live in `app/blog/[slug]/page.tsx`. Date formatting and tag-chip styling mirror the conventions already established in `components/content/post-card.tsx` (duplicated inline rather than extracted — two callers does not yet warrant a shared component). Metadata is exposed via Next 16's `generateMetadata` export on the slug route. No new dependencies; no `lib/` changes.

**Tech Stack:** Next.js 16 App Router (`generateMetadata`, async route handlers), React 19 RSC, TypeScript 5, Tailwind v4 utilities, Vitest 4 + RTL (TDD-Guard gates the loop). Uses existing `getPostBySlug` and `Post` typing from `lib/content.ts`.

## Task 5: Expose OG / Twitter metadata via `generateMetadata`

**Why:** When a post URL is shared on Slack / LinkedIn / X / iMessage, the unfurl currently reads from the site-level metadata (or nothing). Adding per-post `generateMetadata` makes the unfurl show the post's title and summary.

**Files:**
- Modify: `app/blog/[slug]/page.tsx`
- Modify: `app/blog/[slug]/page.test.tsx`

- [ ] **Step 1: Write the failing test**

  Add a new top-level `describe` block in `page.test.tsx`, after the `BlogPost` describe:

  ```ts
  import BlogPost, { generateStaticParams, generateMetadata } from "./page";
  ```

  (Update the existing import line at the top of the file to include `generateMetadata`.)

  Then below the existing tests:

  ```ts
  describe("generateMetadata", () => {
    it("returns title, description and OpenGraph fields for a known post", async () => {
      const meta = await generateMetadata({ params: Promise.resolve({ slug: "welcome" }) });
      expect(meta.title).toBe("Welcome to My Prologue");
      expect(meta.description).toBe("x");
      expect(meta.openGraph?.title).toBe("Welcome to My Prologue");
      expect(meta.openGraph?.type).toBe("article");
      expect(meta.twitter?.card).toBe("summary_large_image");
    });

    it("returns an empty object when the slug does not exist", async () => {
      const meta = await generateMetadata({ params: Promise.resolve({ slug: "missing" }) });
      expect(meta).toEqual({});
    });
  });
  ```

- [ ] **Step 2: Run tests to verify failure**

  ```bash
  pnpm test:run app/blog/\[slug\]/page.test.tsx
  ```
  Expected: the two new tests fail with `generateMetadata is not a function` (or `undefined`). Other tests pass.

- [ ] **Step 3: Implement `generateMetadata`**

  In `app/blog/[slug]/page.tsx`, add at the top:

  ```tsx
  import type { Metadata } from "next";
  ```

  Then, above `generateStaticParams`, export:

  ```tsx
  export async function generateMetadata(
    { params }: { params: Promise<{ slug: string }> },
  ): Promise<Metadata> {
    const { slug } = await params;
    const post = await getPostBySlug(slug);
    if (!post) return {};
    return {
      title: post.title,
      description: post.summary,
      openGraph: {
        title: post.title,
        description: post.summary,
        type: "article",
        publishedTime: post.date,
      },
      twitter: {
        card: "summary_large_image",
        title: post.title,
        description: post.summary,
      },
    };
  }
  ```

- [ ] **Step 4: Run tests to verify green**

  ```bash
  pnpm test:run app/blog/\[slug\]/page.test.tsx
  ```
  Expected: PASS for all `BlogPost` and `generateMetadata` tests in the file.
